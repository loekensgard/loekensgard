## 🌟 Skills

I am currently working as a lead software engineer at [Intility][intility], where I build the APIs, authorization systems, and platform tooling behind software used across Intility's customer base.
In addition to professional projects, I enjoy creating applications for amusement: I have built apps for tracking activity in the company gym, a game for guessing the names of my colleagues, and an advent calendar.

### My top skills include:

**Backend**: C#, .NET, REST APIs, EF Core, SQL Server, PostgreSQL, Redis, Azure Service Bus.\
**Identity**: Entra ID, Azure AD B2C, OAuth/OIDC, RBAC, multi-tenant authorization, Kong, OPA, OpenFGA.\
**Platform**: Kubernetes, OpenShift, ArgoCD, Kustomize, Helm, GitHub Actions, OpenTelemetry.
